# 完整语句

**语句**是 Tanex Script 程序中按顺序执行的代码片段。Tanex Script 中，每个语句都应该是完整的，即使是[注释](注释.md)或[注解](注解.md)。

每个语句都应该以结束符 `;` 结尾

## 语法

`...;`

## 语句的类型

### 普通语句

包括[注释](注释.md)、[注解](注解.md)、零元运算符 `break`/`contiune` 和 import 语句(`->`)。

import 语句用于引入其他 Tanex Script 文件或库。`import` 与 `->` 完全等价，都是**表达式符号**（Pratt 前缀运算符），操作数为**任意表达式**，运行时先求值得到字符串路径再加载：

```tanex script
-> "lib.tsuc";
-> "compiled.tscc";
-> "library_name";
-> "code" + ".tsuc";            # 动态表达式路径
import ["a", "b"] = [x, y];     # 列表批量引入并命名
```

静态字符串字面量在预编译阶段解析为绝对路径（保留原有依赖逻辑）；动态表达式原样保留，运行时动态加载。

引入后只会创建一个 `library` 类型的常量标识符，库内容通过该句柄访问，不会展开到全局作用域。

### 表达式语句

表达式语句是后跟分号的表达式。

Tanex Script 程序中的大多数语句都是表达式语句，例如赋值或函数调用。

### 空语句

表示一个只有结束符 `;` 而没有主要内容的语句，编译器会忽略它们。

## 编译后表示

整个程序文件编译后生成如下结构的 JSON：

```json
{
    "Tanex Script": [
        // 语句1的AST
        // 语句2的AST
        // ...
    ],
    "annotations": {
        // 目标标识符: 注解内容
    },
    "annotation": "文件级注解内容（存在文件级注解时才有）"
}
```

每条语句的AST节点即为该语句表达式的编译结果（如 `binary`、`unary`、`function` 等）。

`annotations` 字段记录了程序中的[注解](注解.md)：以目标标识符为键、注解内容为值。注解语句**不加入** `Tanex Script` 语句列表。

### 特殊语句 AST

| 语句 | AST 格式 | 说明 |
| ------ | --------- | ------ |
| `break;` | `{"break":{"pos":[l,c]}}` | 退出循环（零元运算符，无操作数，单独构成语句） |
| `contiune;` | `{"contiune":{"pos":[l,c]}}` | 立即结束当前循环迭代（零元运算符，无操作数，单独构成语句） |
| `@ 标识符 # 内容 #;` | 记录到 `annotations`，不在 AST 中；无标识符时记录到顶层 `annotation` | 注解语句 |
| `-> <expr>;` / `import <expr>;` | `{"import":{"path":<表达式AST节点>,"name":<标识符或null或标识符列表>,"pos":[l,c]}}` | 导入语句（表达式符号），运行时求值路径并加载为 `library` 常量 |
