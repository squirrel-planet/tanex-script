# 标识符

一个**标识符**是由任意长度的下划线、小写和大写拉丁字母，以及大多数 Unicode 字符组成的序列。

一个有效标识符的任何字符必须是以下之一 (Unicode XID_Start)

- 大写拉丁字母 A-Z
- 小写拉丁字母 a-z
- 下划线
- 所有汉字、日文、韩文、俄文、希腊、阿拉伯字母、泰文等文字字符

**注意**：标识符不能包含数字，如 `1gr`、`4f5`、`std1`、`list2` 都是不合法的命名。

## 在声明中

标识符用于命名变量，但和运算符重名的标识符是非法标识符。

## 在表达式中

命名变量的标识符可以用作表达式。

## 编译后表示

标识符在AST中表示为 `name` 节点：

```json
{"name": {"value": "变量名", "pos": [行, 列]}}
```
