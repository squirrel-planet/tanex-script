# 函数与过程

> 对标 [Python Function Definitions](https://docs.python.org/zh-cn/3.16/reference/compound_stmts.html#function-definitions)
>
> Tanex Script **不区分函数与过程**——统一称为**函数**。所有函数均为一等值，可赋值、传参、返回、存入数据结构。函数本质是带参数信息的 `Code` 类型值。

---

## 1. 函数声明语法

### 1.1 命名函数声明

> **签名**：`*** name = [param1, param2, ...] => { body }`  
> **一句话描述**：在当前作用域声明常量标识符 `name`，绑定一个可调用的 `Code` 值。

#### 参数列表语法

| 形式 | 语法 | 说明 |
|------|------|------|
| 必填参数 | `*name` | 传地址参数，在调用时于函数作用域声明同名变量 |
| 可选参数 | `[*name, type_annotation, default_expr]` | 类型注解(运行时不强制)、默认值表达式(调用时求值) |

- 参数列表为 `List` 字面量语法：`[*a, *b, [*c, integer, `0]]`
- 参数名必须为合法标识符(见 [词法：标识符](lexical.md#标识符))，带 `*` 前缀表示传地址
- 默认值表达式以 **AST 形式暂存**，**调用时**按参数顺序求值补齐
- 无默认值的可选参数，缺省时补 `none`

#### 函数体

代码块 `{ ... }`，惰性求值，调用时执行。

#### 声明特性

- `***` 声明常量标识符，**不可重新赋值**(`name = other_fn` 报错“常量不可修改”)
- 函数值本身可被赋值给其他变量(`* f = name;` 合法)

#### 示例

```tanex script
# 无参函数
*** greet = [] => { $ "Hello!"; };
greet();  # => "Hello!" #;

# 必填参数
*** add = [*a, *b] => { $ a + b; };
add(`3`, `4`);  # => `7 #;

# 可选参数带默认值
*** greet2 = [[*name, string, "World"]] => { $ "Hello, " + name + "!"; };
greet2();        # => "Hello, World!" #;
greet2("Tanex"); # => "Hello, Tanex!" #;

# 多参数混合
*** demo = [*required, [*opt, integer, `0]] => { $ required + opt; };
demo(`1`);      # => `1 #;
demo(`1`, `2`); # => `3 #;
```

### 1.2 匿名函数

> **签名**：`[param1, param2, ...] => { body }`  
> **一句话描述**：构造一个不绑定标识符的可调用 `Code` 值。

语法与命名函数参数列表完全一致。详见 [表达式：匿名函数](expressions.md#匿名函数-=>)。

## 2. 参数传递机制

### 2.1 传地址

**核心规则**：所有参数**传地址**(Call by Address)。

```tanex script
*** modify = [*x] => { x = `999; };
* a = `1;
modify(a);
a;  # => `999 (调用方变量被修改) #;
```

- 调用方为每个实参在**调用方地址空间**分配临时存储单元，传递该地址给被调函数
- 被调函数在**新建子作用域**中声明同名变量(`*param_name`)，绑定到传入的地址
- **效果**：函数内对参数赋值(`param = new_val`)直接修改调用方对应变量的存储单元

### 2.2 参数绑定顺序与默认值

1. 实参按位置顺序与形参一一对应
2. 实参数 < 形参数：缺失位置的形参按**默认值表达式求值**补齐；无默认值补 `none`
3. 实参数 > 形参数：多余实参**报错**“参数过多”
4. 默认值求值发生在**调用时**，在函数子作用域建立前，按参数顺序左到右求值

```tanex script
*** fn = [*a, [*b, integer, `10], [*c, integer, `20]] => { $ a + b + c; };
fn(`1`);       # => `31 (b=10, c=20) #;
fn(`1`, `2`);  # => `23 (b=2, c=20) #;
fn(`1`, `2`, `3`); # => `6 (b=2, c=3) #;
# fn(`1`, `2`, `3`, `4`); # 报错：参数过多
```

### 2.3 可变参数

> **当前版本不支持可变参数**(`*args`、`**kwargs` 等)。如需变长参数，约定传入 `List` 并在函数内遍历。

```tanex script
*** sum_all = [*list] => {
    * total = `0;
    for(* item, list, { total = total + item; });
    $ total;
};
sum_all([`1`, `2`, `3`, `4`]);  # => `10 #;
```

## 3. 返回值

### 3.1 显式返回

- `$ expression` 或 `return expression`：提前结束函数/代码块执行，携带值返回
- 在 `$$` 循环体内：`$` 语义为**收集**(值加入收集列表)，不结束循环

### 3.2 隐式返回

- 函数/代码块**无显式 `$`** 时：最后一条语句的求值结果作为返回值
- 空函数/代码块：返回 `none`

### 3.3 返回值类型

- 无限制，可返回任意类型值(含 `Code`、`Type`、`Library` 等)
- 多返回值约定：返回 `List` 或多值拼接(语言无原生多返回值语法)

```tanex script
*** explicit = [*x] => { $ x * `2; };
*** implicit = [*x] => { x * `2; };  # 最后一句是表达式语句，值为乘法结果
explicit(`5`);  # => `10 #;
implicit(`5`);  # => `10 #;
```

## 4. 作用域与闭包

### 4.1 定义时作用域捕获

- 函数创建时(命名函数声明执行、匿名函数表达式求值)，**捕获当前作用域引用**存入 `Code` 对象的 `scope` 字段
- 此作用域为**词法作用域**(定义位置决定，非调用位置)

### 4.2 调用时子作用域建立

- 函数调用时：基于捕获的 `scope` 创建**新子作用域**(父作用域指向捕获的作用域)
- 参数在子作用域中声明(`*param_name`)，绑定到传入地址
- 函数体在子作用域中执行

### 4.3 闭包捕获外部变量

```tanex script
*** make_counter = [*init] => {
    * count = init;  # 在 make_counter 的局部作用域
    [*] => {         # 返回的匿名函数捕获外层作用域
        count = count + `1;  # 修改外层 count
        $ count;
    };
};

* c1 = make_counter(`0);
* c2 = make_counter(`100);
c1();  # => `1 #;
c1();  # => `2 #;
c2();  # => `101 (独立环境) #;
```

- 捕获的是**变量地址**(存储单元)，非值快照
- 外层变量修改对闭包可见，闭包内修改对外层可见
- 每次调用 `make_counter` 创建新的 `count` 存储单元，形成独立闭包环境

### 4.4 上级访问 `~` 与闭包

- `~expr` 在**父作用域**求值，可穿透闭包层级访问外层变量
- 闭包捕获的作用域链包含所有外层作用域，`~` 沿此链向上

## 5. 高阶函数模式

### 5.1 函数作为值

```tanex script
* fns = [add, sub, mul];  # 函数列表
fns[`0`](`5`, `3`);  # => `8 (动态调用列表中第一个函数) #;

*** apply = [*fn, *x, *y] => { $ fn(x, y); };
apply(add, `10`, `20`);  # => `30 #;
```

### 5.2 柯里化

```tanex script
*** curry_add = [*a] => {
    [*b] => { $ a + b; };
};
* add5 = curry_add(`5`);
add5(`3`);  # => `8 #;
```

### 5.3 回调模式

```tanex script
*** map = [*list, *fn] => {
    * result = List{};
    for(* item, list, {
        result.append(fn(item));
    });
    $ result;
};

* doubled = map([`1`,`2`,`3`], [*x] => { $ x * `2; });
# => [`2`, `4`, `6`] #;
```

### 5.4 管道操作符 `|>`

```tanex script
`5` |> [*x] => { $ x * `2; } |> [*y] => { $ y + `1; };  # => `11 #;

# 等价于嵌套调用
[*y] => { $ y + `1; }(([*x] => { $ x * `2; })(`5));
```

## 6. 递归

### 6.1 直接递归

```tanex script
*** factorial = [*n] => {
    n <= `1 ? { $ `1; } : { $ n * factorial(n - `1); };
};
factorial(`5`);  # => `120 #;
```

### 6.2 相互递归

```tanex script
*** even = [*n] => { n == `0 ? { $ true; } : { $ odd(n - `1); }; };
*** odd = [*n] => { n == `0 ? { $ false; } : { $ even(n - `1); }; };
even(`4`);  # => true #;
```

### 6.3 递归深度限制

- 无尾调用优化 (TCO)
- 默认递归限制 ~1000 层(可配置 `recursion_limit`)
- 深度递归建议改用 `$$` 循环或 `cycle`

```tanex script
# 尾递归改写为循环
*** fact_iter = [*n, *acc] => {
    n <= `1 ? { $ acc; } : { $ fact_iter(n - `1, n * acc); };
};
*** factorial = [*n] => { $ fact_iter(n, `1); };
```

## 7. 控制流函数标准签名

> 以下函数在引导库 `bootstrap.tsuc` 中以 Tanex Script 实现，作为**标准库函数**提供。非语言关键字，可被遮蔽/重定义。

| 函数 | 签名 | 说明 |
|------|------|------|
| `if` | `if(cond, then_code, else_code)` | 条件分支 |
| `for` | `for(*var, iterable, body_code)` | 遍历循环 |
| `while` | `while(cond_code, body_code)` | 条件循环 |
| `cycle` | `cycle(times, body_code)` | 定次循环 |
