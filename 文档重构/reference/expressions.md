# 表达式

> 对标 [Python Expressions](https://docs.python.org/zh-cn/3.16/reference/expressions.html)
>
> 表达式是运算符与操作数的序列，指定了计算。每个表达式具有**值**与**类型**两属性。

---

## 1. 求值顺序

### 1.1 一般原则

- **无固定左右求值顺序**：编译器根据[运算符优先级](../reference/index.md#运算符优先级总表-高低)决定求值顺序，运行时按编译器规定顺序求值
- **短路求值**：`&&`、`||`、`?:`、`|` 尝试结构仅求值必要分支
- **函数参数**：实参按位置顺序**左到右求值**，再传递给函数
- **赋值**：右侧表达式**先于**左侧赋值目标求值
- **代码块**：惰性求值，创建时不执行，调用时才执行

### 1.2 特殊求值规则

| 表达式 | 求值顺序 |
|--------|----------|
| `a + b` | 按优先级：先求值操作数，再调用 `addition` |
| `a && b` | 先求 `a`，真则求 `b`，假则短路返回 `a` |
| `a || b` | 先求 `a`，假则求 `b`，真则短路返回 `a` |
| `cond ? t : f` | 先求 `cond`，真求 `t`，假求 `f` |
| `left | *e : catch : else` | 先求 `left`，报错则绑定错误求 `catch`，否则求 `else` |
| `Type{...}` | 先求类型表达式，再求参数列表，最后调用 `initialize` |
| `f(a, b)` | 先求 `f`，再左到右求实参，最后调用 |
| `a[b]` | 先求 `a`，再求 `b`，最后调用 `index` |

## 2. 原子表达式

### 2.1 字面量

| 字面量 | 语法 | 类型 | 示例 |
|--------|------|------|------|
| 整数 | `` `123` `` | `Integer` | `` `42` `` |
| 数字 | `'3.14'` | `Number` | `'2.5'` |
| 字符串 | `"hello"` | `String` | `"hi\n"` |
| 布尔 | `true` / `false` | `Boolean` | `true` |
| 空值 | `none` | `NoneType` | `none` |
| NaN | `nan` | `NaNType` | `nan` |
| 无穷 | `infinite` / `-infinite` | `InfiniteType` | `infinite` |

- 所有字面量 AST 节点含 `pos: [line, column]`
- 求值**无副作用**，直接产生对应类型值

### 2.2 标识符

- **语法**：`name` (合法标识符，见 [词法：标识符](lexical.md#标识符))
- **求值**：在当前作用域解析名字，获取关联地址，从地址空间读取值返回
- **未定义**：报错“变量未定义：`name`”

### 2.3 分组 `()`

- **语法**：`( expression )`
- **求值**：求值内部表达式，返回其值。**不引入新作用域**
- **用途**：覆盖优先级、分组复杂表达式

### 2.4 代码块字面量 `{...}`

> **签名**：`{ statement1; statement2; ... }`  
> **一句话描述**：创建 `Code` 类型值，捕获当前作用域，惰性求值。

**详细说明**：
- 不立即执行，产生 `code` 类型值
- 内部字段：`statements`(语句AST列表)、`scope`(定义时作用域)、`params`(`None`，仅匿名函数有参数信息)
- 作为值可赋值、传参、存入数据结构
- 执行入口：函数调用、控制流函数(`if`/`for`/`while`/`cycle`)、`$$` 循环符
- 代码块内 `$ expr` 表示提前返回(被 `$$` 收集则改为收集语义，见 [循环符](#循环符-))

**示例**：
```tanex script
* block = { std.standard_output << "hello\n"; $ `42; };
block();  # => 输出 hello, 返回 `42 #;
```

### 2.5 列表字面量 `[...]`

> **签名**：`[ expr1, expr2, ..., exprN ]`  
> **一句话描述**：创建 `List` 实例，元素按顺序求值存入单向链表。

**规则**：
- 元素**左到右求值**，每个求值结果存入新链表节点
- **尾部逗号**：`[a,]` 合法，自动填充 `none`
- **中间空位**：`[a,,b]` 合法，空位填充 `none`
- 空列表 `[]` 创建空链表(`head=tail=none, size=0`)

## 3. 一元运算符

> 所有一元运算符为**前缀**形式，优先级见 [运算符优先级](../reference/index.md#运算符优先级总表-高低)。右结合。

| 运算符 | 名称 | 详细条目 |
|--------|------|----------|
| `~` | 上级访问 | [一元：上级访问](#一元上级访问) |
| `!` | 逻辑非 | [一元：逻辑非](#一元逻辑非) |
| `*` | 解地址/声明符 | [一元：解地址](#一元解地址) |
| `/` | 取地址 | [一元：取地址](#一元取地址) |
| `**` | 引用声明 | [一元：引用声明](#一元引用声明) |
| `***` | 常量声明/特殊成员 | [一元：常量声明](#一元常量声明) |
| `&` / `&&` / `&&&` | 连续声明 | [一元：连续声明](#一元连续声明) |
| `<-` | 抛出错误 | [一元：抛出错误](#一元抛出错误) |
| `$` / `return` | 返回 | [一元：返回](#一元返回) |
| `??` | 注解读取 | [一元：注解读取](#一元注解读取) |
| `type_of` | 类型查询 | [一元：类型查询](#一元类型查询) |
| `+` / `-` | 一元正负 | [一元：正负号](#一元正负号) |

### 3.1 条目详情

#### 一元：上级访问 `~ expr`

在**父作用域**求值操作数。无父作用域时报错。可连续：`~~x`。

#### 一元：逻辑非 `! expr`

真值判定后取反，返回 `true`/`false`。等价 `expr ? false : true`。

#### 一元：解地址 `* expr`

操作数为 `Address` 或标识符。标识符未声明时自动分配地址并声明。解地址赋值 `*addr = val` 写入值。

#### 一元：取地址 `/ expr`

求值操作数得左值，返回其地址(`Address`类型)。标识符未声明时自动分配。

#### 一元：引用声明 `** expr`

声明引用变量，与目标标识符共享存储单元。操作数必须为标识符。

#### 一元：常量声明 `*** expr`

声明常量变量(标记存储单元只读)，或在类型上注册特殊成员(`*** Type.member = fn`)。

#### 一元：连续声明 `& N` / `&& N` / `&&& N`

一次性声明 N 个连续存储单元，返回 `[start, end]` 列表。`N` 必为正整数字面量。

#### 一元：抛出错误 `<- expr`

求值 `expr` 得值 `v`，抛出内部 `ErrorSignal(v)`。仅能被 `|` 捕获。

#### 一元：返回 `$ expr` / `return expr`

提前结束当前代码块/函数，携带值返回。`$$` 内变为收集模式。

#### 一元：注解读取 `?? expr`

按作用域读取标识符注解，返回字符串；支持 `?? lib.member` 跨库读取。未找到返回 `none`。

#### 一元：类型查询 `type_of expr`

返回操作数值的类型对象(`Type`类型值)。

#### 一元：正负号 `+ expr` / `- expr`

内置数值类型保持行为；用户类型可重载 `positive`/`negative` 特殊成员。

## 4. 二元运算符

> 所有二元运算符为**中缀**形式，优先级、结合性见 [运算符优先级](../reference/index.md#运算符优先级总表-高低)。除标注短路外，均**先求值左右操作数**再执行运算。

### 4.1 算术运算符

| 运算符 | 名称 | 特殊成员 | 优先级 | 结合性 |
|--------|------|----------|--------|--------|
| `+` | 加法/拼接 | `addition` | 9 | 左 |
| `-` | 减法 | `subtract` | 9 | 左 |
| `*` | 乘法/重复 | `multiply` | 8 | 左 |
| `/` | 除法 | `divide` | 8 | 左 |
| `\` | 整数除法 | `exactly_divisible` | 8 | 左 |
| `%` | 取余 | `modulo` | 8 | 左 |
| `^` | 幂运算 | `power` | 8 | 左 |

**通用语义**：
- 左操作数类型决定调用哪个类型的特殊成员
- `Integer` 与 `Number` 混合运算：`Integer` 提升为 `Number` 后运算
- 字符串/列表 `+` 为拼接，`*` 为重复
- 除零：`/` 产生 `infinite`/`nan`；`\`、`%` 报错

### 4.2 输出/输入：`<<` `>>`

| 运算符 | 语义 |
|--------|------|
| `left << right` | 输出：右操作数调用 `string` 得字符码链表，交给左操作数处理函数逐字符输出 |
| `left >> right` | 输入：读取输入字符串，左操作数处理后写入右操作数地址 |

### 4.3 管道：`|>`

> **签名**：`left |> right`  
> **语义**：首参注入，`a |> f` 等价 `f(a)`。右侧必须为函数引用(标识符/成员访问)，不支持带参调用。链式左结合。

### 4.4 循环符：`$$`

> **签名**：`condition $$ body`  
> **语义**：左操作数为条件、右为循环体。条件为真时执行循环体，收集 `$` 返回值形成列表，直到条件为假或遇到 `break`。

**条件求值形式**：
1. 实例且类型有 `initialize`：调用 `initialize(实例自身)`，结果按真值判定
2. 实例但类型无 `initialize`：直接视为假
3. 代码块：作为条件函数执行
4. 其他值：直接按真值判定

**循环体内**：
- `$ expr`：收集模式，值追加到列表，**不**结束循环
- `break`：立即退出，返回已收集列表
- `contiune`：结束本轮迭代，重新求值条件

### 4.5 比较运算符

| 运算符 | 特殊成员 | 优先级 | 兜底规则 |
|--------|----------|--------|----------|
| `<` | `less` | 10 | `!(greater \|\| equal)` |
| `<=` | `less_equal` | 10 | `!greater` |
| `>` | `greater` | 10 | `!(less \|\| equal)` |
| `>=` | `greater_equal` | 10 | `!less` |
| `==` | `equal` | 11 | `!not_equal` |
| `!=` | `not_equal` | 11 | `!equal` |

**兜底链**：直接特殊成员 → 组合兜底 → `compare` 三路比较 → 对象同一性兜底

### 4.6 逻辑与/或：`&&` `||` (短路)

| 运算符 | 优先级 | 短路规则 |
|--------|--------|----------|
| `&&` | 12 | 左假 → 返回左值，不求右 |
| `||` | 13 | 左真 → 返回左值，不求右 |

返回**最后一个被求值操作数的值**(非规范化布尔值)。

### 4.7 存在判断：`in`

> **签名**：`left in right`  
> **语义**：优先调用右操作数类型的 `include` 特殊成员；兜底用 `index`+`size` 遍历比较。无 `index` 报错。

### 4.8 赋值运算符

| 运算符 | 语义 |
|--------|------|
| `=` | 解析左侧赋值目标得地址，求值右侧，写入 |
| `+=` 等复合赋值 | 读旧值 → 运算 → 写回(左侧只求值一次) |

**赋值目标解析**：
- 标识符 → 作用域查找/分配地址
- 成员访问 `obj.field` → 对象成员查找/分配
- 下标 `obj[key]` → 调用 `index` 得地址/`value`成员地址
- 声明符 `*name`/`**name`/`***name` → 分配新地址，`***` 额外标记常量
- `*** Type.member` → 类型对象上创建/覆盖成员，标记常量

### 4.9 成员访问 `.`

> **签名**：`left.right`  
> **语义**：实例：实例成员 → 类型成员 → 继承链。类型：类型成员 → 继承链。可用于赋值左侧。

### 4.10 下标访问 `[]`

> **签名**：`left[right]`  
> **语义**：左类型有 `index` 则调用；无 `index` 但有 `initialize` 则调用构造器；否则报错。可用于赋值左侧。

### 4.11 实例创建 `{}`

> **签名**：`Type{arg1, arg2, ...}`  
> **语义**：创建类型 `Type` 新实例，调用 `initialize`(若存在)。见 [类型构造](types.md#类型构造与初始化)。

### 4.12 匿名函数：`=>`

> **签名**：`[param1, param2, ...] => { body }`  
> **语义**：从左侧参数列表提取参数信息植入右侧代码块，返回可调用 `Code` 值。

### 4.13 多层跳出：`$` (二元)

> **签名**：`n $ m`  
> **语义**：向上跳出 `n` 层代码块/函数，返回目标并返回 `m`。`1 $ m` 等价 `return m`。层数不足报错。

## 5. 三目与尝试结构

### 5.1 三目运算符：`cond ? t : f`

> **签名**：`condition ? true_branch : false_branch`  
> **语义**：按真值判定条件，真返回 `true_branch`，假返回 `false_branch`。仅求值选中分支。右结合。

### 5.2 尝试结构：`left | *err : catch : else`

> **签名**：`left | *err : catch_block : else_block`  
> **语义**：尝试执行 `left`，成功执行 `else_block`(可选)；报错则绑定错误到 `*err` 执行 `catch_block`。唯一能拦截报错的语法。

**错误绑定作用域**：`*err` 在当前作用域声明/覆盖，`catch_block` 可直接访问。
