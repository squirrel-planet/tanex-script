## 2. 行结构

### 2.1 行终止符

| 序列 | 码点 | 处理 |
|------|------|------|
| LF | U+000A | 换行 |
| CR | U+000D | 换行 |
| CRLF | U+000D U+000A | 单个换行 |

**关键规则**：换行符**与空格、制表符同属空白字符**，词法分析阶段直接跳过，**不终结语句**。语句仅由分号 `;` 终结。

### 2.2 无续行语法

- **无续行符**：行尾**不需要、也不允许**任何续行符
- **反斜杠 `\` 是二元整除运算符** (见 [表达式：整除](../expressions.md#整除))

```tanex script
# 正确：自由换行
a = `100
+ `200
+ `300;  # => `600 #;

# 错误：行尾 \ 被解析为整除
# a = `10 \   # 整除左操作数
# `2;         # 右操作数，等价 a = `10 \ `2 结果 5
```

| 换行符 | U+000A/U+000D | 词法分隔，**不终结语句** |

## 4. 注释

### 4.1 语法

```tanex script
# 单行注释 #;
# 多行注释
支持任意内容
包括运算符、关键字、未闭合引号
#;
```

### 4.2 规则

| 项目 | 规范 |
|------|------|
| **起止标记** | `#` 开始、`#` 结束，**必须成对** |
| **嵌套** | **不支持嵌套**。首个 `#` 后的下一个 `#` 即为结束 |
| **跨行** | 支持任意行数 |
| **位置** | 可出现在任意空白处。**不能出现在字符串/数字字面量内部** |
| **编译产物** | 词法识别为 `comment` Token，语法分析**完全忽略**，不进入 AST |

### 4.3 文档注释约定

建议：模块/函数/类型前放置 `# 功能简述 #;` 单行注释；详细说明用注解 `@`。

## 5. 注解

注解是**编译期元数据**，源码中写入，编译器收集进编译产物 `annotations` 字段，运行时通过一元运算符 `??` 读取。

### 5.1 语法

```tanex script
@ 标识符 # 注解内容 #;
@ # 文件级注解内容 #;           # 无标识符 = 文件级注解
@ Type.member # 成员注解 #;       # 成员级注解，键为 "Type.member"
```

| 组成部分 | 规则 |
|----------|------|
| **起始** | `@` 符号 |
| **目标标识符** | 可选。合法标识符、或 `Type.member` 形式。省略 = 文件级注解 |
| **内容分隔** | 单个 `#` 分隔标识符与内容 |
| **内容** | 任意字符(除 `#;` 结束序列外)，支持多行 |
| **结束** | `#;` 两字符序列，**必须成对** |
| **语句性质** | **完整语句**，隐含分号语义 |

### 5.2 编译产物表示

```json
{
  "Tanex Script": [ ...语句AST... ],
  "annotations": {
    "my_func": "这是 my_func 的文档。",
    "String.length": "返回字符串长度"
  },
  "annotation": "这是文件级注解内容"   // 仅存在文件级注解时出现
}
```

- `annotations`：目标标识符 → 注解内容字符串映射。**注解语句不进入语句列表**
- `annotation`：文件级注解内容(字符串)

### 5.3 作用域与读取

| 读取形式 | 作用域 | 示例 |
|----------|--------|------|
| `?? name` | 当前文件/顶层作用域(含引导库、已 import 库的文件级注解) | `?? my_func` |
| `?? lib.member` | 已导入库 `lib` 的**独立注解空间** | `?? standard.for` |
| `?? Type.member` | 当前作用域的成员级注解(键为 `"Type.member"`) | `?? String.length` |

**库注解隔离**：`import "lib" = *h;` 时，`lib` 的注解写入独立空间，**不平铺**到顶层。

## 6. 标识符

### 6.1 合法字符集

标识符由 **Unicode XID_Start** 字符开始，后续为 **Unicode XID_Continue** 字符。

| 类别 | 示例 | 说明 |
|------|------|------|
| 大写拉丁字母 | `A`–`Z` | ✅ |
| 小写拉丁字母 | `a`–`z` | ✅ |
| 下划线 | `_` | ✅ 可作首字符 |
| 汉字/日文/韩文/俄文/希腊/阿拉伯/泰文等字母字符 | `变量`、`変数`、`변수` 等 | ✅ 视为字母 |
| **数字** | `0`–`9` | ❌ **禁止出现在标识符任何位置** |

### 6.2 非法示例

```tanex script
1var;      # ❌ 以数字开头
var1;      # ❌ 包含数字
std1;      # ❌ 包含数字
list2;     # ❌ 包含数字
my-var;    # ❌ 连字符非 XID_Continue (按运算符 `-` 解析)
```

### 6.3 保留字(关键字)

以下标识符**不能**用作变量/函数/类型名，仅作为语法标记：

| 关键字 | 语法角色 | 别名/备注 |
|--------|----------|-----------|
| `import` | 表达式符号(前缀运算符) | 等价 `->` |
| `true` / `false` | 布尔字面量 | — |
| `none` | 空值字面量 | — |
| `nan` | NaN 字面量 | — |
| `infinite` | 无穷字面量 | — |
| `break` | 零元运算符 | — |
| `contiune` | 零元运算符 | 拼写固定为 `contiune` |
| `return` | 一元运算符 | 等价 `$` |
| `and` / `or` / `not` / `is` | 词法别名 | 自动转为 `&&`/`||`/`!`/`==` |

> **注意**：`if`、`for`、`while`、`cycle` **不是**关键字，它们是标准库函数名，可被遮蔽或重新定义。

### 6.4 命名约定(建议，非强制)

| 实体 | 约定 | 示例 |
|------|------|------|
| 变量/函数/参数 | `snake_case` | `my_var`、`calculate_sum` |
| 类型/类 | `PascalCase` | `MyType`、`StringBuilder` |
| 常量(`***`声明) | `UPPER_SNAKE_CASE` | `MAX_SIZE`、`DEFAULT_TIMEOUT` |
| 模块/库名 | `lowercase` | `standard`、`maths`、`encoding.ascii` |
| 内部/私有成员 | `_snake_case` 前缀下划线 | `_internal_cache` |

## 7. 关键字别名

词法分析阶段**自动替换**为对应运算符，**不产生独立 Token**：

| 关键字 | 替换为 | 优先级/结合性 | 示例 |
|--------|--------|---------------|------|
| `and` | `&&` | 同 `&&`(优先级 12，左结合) | `a and b` → `a && b` |
| `or` | `||` | 同 `||`(优先级 13，左结合) | `a or b` → `a || b` |
| `not` | `!` | 同 `!`(优先级 5，右结合前缀) | `not a` → `!a` |
| `is` | `==` | 同 `==`(优先级 11，左结合) | `a is b` → `a == b` |

**设计意图**：提供类英语可读性，不增加语法复杂度。解析器仅见运算符 Token。

## 8. 字面量

### 8.1 整数字面量 (`Integer`)

```tanex script
`0`; `42`; `1_000_000`; `999999999999999999999`;
```

| 规则 | 说明 |
|------|------|
| **进制** | 仅十进制(无 `0x`/`0o`/`0b` 前缀) |
| **下划线分隔** | 数字间可插入 `_` 增强可读性，编译时忽略(`1_000` ≡ `1000`) |
| **首尾/连续下划线** | ❌ 禁止：`_100`、`100_`、`1__000` |
| **符号** | 无符号。负数用一元 `-`：`-` `42` |
| **取值范围** | 理论无上限(受限内存) |
| **类型** | 原类型 `integer`，**不包装实例** |

### 8.2 数字字面量 (`Number`)

```tanex script
'3.14'; '-2.5'; '0'; '100'; '0.0001'; '-0.0';
```

| 规则 | 说明 |
|------|------|
| **包裹符** | **单引号 `'`** 成对包裹(`'...'`) |
| **组成** | 可选符号(`+`/`-`)、整数部分、可选小数点 `.` + 小数部分 |
| **整数部分** | 必须至少一位数字(`'.5'` ❌，`'0.5'` ✅) |
| **小数部分** | 小数点后必须至少一位数字(`'5.'` ❌，`'5.0'` ✅) |
| **下划线** | ❌ 不支持 |
| **内部表示** | 精确十进制：`front`(整数部分 `Integer`) + `back`(小数部分 `Integer`) + 隐含小数位数 |
| **运算语义** | 加减乘除对齐小数位、进位处理，**无浮点误差** |

### 8.3 字符串字面量 (`String`)

```tanex script
"hello"; "中文\n"; "\"quoted\""; "\\path\\to\\file";
```

| 规则 | 说明 |
|------|------|
| **包裹符** | **双引号 `"`** 成对包裹(`"..."`) |
| **转义序列** | 见下表，**仅支持列表内序列**，其它 `\x` 按原义 |
| **原始字符串** | 暂不支持(无 `r"..."` 语法) |
| **内部存储** | Unicode 码点序列，底层 `list` 链表，每节点存一个码点 |

#### 转义序列表

| 转义 | 码点 | 字符 |
|------|------|------|
| `\n` | 10 | LF 换行 |
| `\t` | 9 | HT 制表符 |
| `\"` | 34 | 双引号 |
| `\\` | 92 | 反斜杠 |
| `\r` | 13 | CR 回车 |
| `\b` | 8 | BS 退格 |
| `\f` | 12 | FF 换页 |
| `\v` | 11 | VT 垂直制表符 |

### 8.4 布尔字面量 (`Boolean`)

```tanex script
true; false;
```

- 仅两个值，存储 `1`(真)或 `0`(假)
- 算术运算返回 `Integer` 类型

### 8.5 特殊字面量

| 字面量 | 类型 | 说明 |
|--------|------|------|
| `none` | `NoneType` | 全局单例，真值恒假 |
| `nan` | `NaNType` | 非数字标记，运算溢出产生 |
| `infinite` | `InfiniteType` | 正无穷(`1/0` 产生) |
| `-infinite` | `InfiniteType` | 负无穷 |

## 9. 运算符符号表

以下为语言**固定**的运算符符号集合。**不可增删改**，语法已冻结。

| 种类 | 符号列表 | 备注 |
|------|----------|------|
| **一元前缀** | `!` `~` `*` `/` `**` `***` `&` `&&` `&&&` `<-` `return` `??` `type_of` `+` `-` | `return` 等价 `$`；`type_of` 为关键字形式一元运算符 |
| **二元中缀** | `+` `-` `*` `/` `\` `%` `^` `<<` `>>` `$$` `|>` `<` `<=` `>` `>=` `==` `!=` `&&` `||` `in` `=` `+=` `-=` `*=` `/=` `\=` `%=` `^=` `&=` `|=` `$`(二元) `.` `[]` `{}` `=>` | `$` 二元为多层跳出；`.` 成员访问；`[]` 下标；`{}` 实例创建；`=>` 匿名函数 |
| **三目** | `? :` | `cond ? t : f` |
| **三元(尝试)** | `\| : :` | `left \| *err : catch : else` |
| **零元** | `break` `contiune` | 独立语句，无操作数 |
| **表达式符号(前缀)** | `import` `->` | Pratt 前缀，操作数为任意表达式，绑定优先级 `prec_assign + 1` |
| **分隔/结构** | `;` `,` `(` `)` `[` `]` `{` `}` `#` `#;` `@` | `;` 语句终结；`,` 列表/参数分隔；`#` `#` 注释；`#;` 注解结束；`@` 注解开始 |

**重载性**：
- 所有二元算术/比较/逻辑运算符可通过类型特殊成员重载
- 一元 `+` `-` `!` `~` `*` `/` `??` `type_of` 可重载
- 赋值 `=`、`+=` 等、**零元**、**表达式符号**、**三目/尝试结构**、**成员访问 `.`**、**下标 `[]`**、**实例创建 `{}`**、**匿名函数 `=>`**、**管道 `|>`**、**多层跳出 `$`(二元) **不可重载**
