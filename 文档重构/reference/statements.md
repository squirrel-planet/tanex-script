# 语句

> 对标 [Python Simple Statements](https://docs.python.org/zh-cn/3.16/reference/simple_stmts.html)
>
> 语句是程序中按顺序执行的代码片段。**每条语句必须以分号 `;` 结尾**。换行只是空白，不终结语句。

---

## 1. 语句分类完备表

| 语句类型 | 语法示例 | 进入 AST | 说明 |
|----------|----------|----------|------|
| **表达式语句** | `a = `1`;`、`f();`、` `1` + `2`;` | ✅ | 任意表达式 + `;` |
| **空语句** | `;` | ❌ | 编译器忽略，无 AST 节点 |
| **简单声明** | `* x;`、`* y = `10`;` | ✅ (`unary` `*`) | 引入标识符，可选初始化 |
| **引用声明** | `** r = x;` | ✅ (`unary` `**`) | 声明引用变量，右值必须为标识符 |
| **常量声明** | `*** C = `100`;` | ✅ (`unary` `***`) | 标记存储单元只读 |
| **数量声明** | `* 5;`、`** 3;`、`*** 4;` | ✅ (`unary` 操作数为字面量) | 分配 N 个连续空间，返回 `[start,end]` |
| **连续声明** | `& 5;`、`&& 3;`、`&&& 4;` | ✅ (`unary` `&`/`&&`/`&&&`) | 等价数量声明，一元位置专用 |
| **赋值声明** | `x = `1`;`、`x += `2`;` | ✅ (`assignment`) | 含复合赋值 |
| **导入语句** | `import "lib";`、`-> "file";`、`import [a,b] = [*x,*y];` | ✅ (`import`/`include`) | 表达式符号，运行时求值路径加载 |
| **零元语句** | `break;`、`contiune;` | ✅ (`break`/`contiune`) | 仅在 `$$` 循环内生效 |
| **注解语句** | `@ name # doc #;` | ❌ (记录到 `annotations`) | 不进入语句列表 |
| **文件级注解** | `@ # file doc #;` | ❌ (记录到 `annotation`) | 不进入语句列表 |

---

## 2. 表达式语句

> **语法**：`expression;`
> **行为**：求值表达式，丢弃结果(除非有副作用：赋值、函数调用、I/O、抛出错误等)。
> **AST**：表达式 AST 直接作为语句节点。

```tanex script
`1` + `2`;              # 求值丢弃
std.standard_output << "hi\n";  # 副作用：输出
x = `10`;               # 副作用：赋值
f();                    # 副作用：函数调用
```

---

## 3. 空语句

> **语法**：`;`
> **行为**：无操作，编译器忽略，**不进入 AST**。

---

## 4. 声明语句

### 4.1 简单声明

> **签名**：`* identifier;`、`* identifier = expression;`

| 形式 | 行为 |
|------|------|
| `* name;` | 声明 `name`，分配新地址，初值 `none`，返回地址 |
| `* name = expr;` | 声明 `name`，求值 `expr` 写入，返回地址 |
| `name = expr;` | **赋值声明**：若 `name` 未声明，隐式声明(等价 `* name = expr`)，已声明则普通赋值 |

- `*` 声明符在赋值时可省略(`name = expr` 兼容隐式声明)
- 返回声明变量的地址(`Address`类型)

### 4.2 引用声明

> **签名**：`** identifier = identifier;`
- 右值**必须为标识符**(不能是表达式)
- 声明引用变量，与目标共享存储单元
- 返回引用变量地址

### 4.3 常量声明

> **签名**：`*** identifier;`、`*** identifier = expression;`
- 声明常量变量，分配地址，**标记只读**，可选初始化
- 后续任何赋值报错“常量不可修改”

### 4.4 数量声明

> **签名**：`* N;`、`** N;`、`*** N;`
- 操作数 `N` 为整数/整数值 `Number` 字面量
- 分配 N 个连续空间，返回 `[start_addr, end_addr]` 列表
- `* N` 普通、`** N` 引用、`*** N` 常量空间

### 4.5 连续声明(一元运算符形式)

> **签名**：`& N;`、`&& N;`、`&&& N;`
- 等价于对应数量声明，一元位置专用运算符形式
- `&&` 二元位置仍为逻辑与

## 5. 赋值语句

> **签名**：`target = expr;`、`target += expr;` 等

### 5.1 赋值目标解析

| 左侧 AST 类型 | 解析动作 |
|---------------|----------|
| 标识符 `name` | 当前作用域查找/分配地址 |
| 成员访问 `obj.field` | 求值 `obj`，在对象成员中查找/分配 `field` 地址 |
| 下标访问 `obj[key]` | 求值 `obj`、`key`，调用 `index` 特殊成员得地址/`value` 成员地址 |
| 一元声明符 `*name`/`**name`/`***name` | 分配新地址，`***` 额外标记常量 |
| `*** Type.member` | 在类型对象上创建/覆盖成员，标记常量 |

### 5.2 复合赋值

`target += expr` 等价于 `target = target + expr`(但 `target` 只求值一次、只解析一次目标地址)。

### 5.3 特殊赋值目标(`***` 前缀触发)

| 目标形式 | 特殊处理 |
|----------|----------|
| `*** name` | 标记地址为常量 |
| `*** Type.initialize` | 设置类型构造器 |
| `*** Type.boolean` | 设置布尔转换特殊成员 |
| `*** Type.string` | 设置字符串转换特殊成员 |
| `*** Type.index` | 设置索引特殊成员 |
| `*** Type.addition` 等 7 算术 | 设置对应算术特殊成员 |
| `*** Type.positive`/`negative` | 设置一元正负特殊成员 |
| `*** Type.greater` 等 6 比较 | 设置对应比较特殊成员 |
| `*** Type.compare` | 设置三路比较特殊成员 |
| `*** Type.inherit` | 设置继承目标，触发全量成员复制(跳过三字段) |

## 6. 导入语句

> **签名**：`import expression;`、`-> expression;` 及命名/列表变体。

详见 [模块系统](modules.md)。

### 6.1 形式速查

| 形式 | 示例 | 说明 |
|------|------|------|
| 单条引入 | `import "lib";` | 绑定到标识符 `lib` |
| 命名引入 | `import "lib" = *m;` | 库实例地址引用绑定到 `m` |
| 列表批量 | `import ["a", "b"];` | 分别绑定到 `a`、`b` |
| 列表命名 | `import ["a", "b"] = [*x, *y];` | 绑定到 `x`、`y` |
| 动态路径 | `import "lib_" + suffix;` | 运行时求值 |
| 展开引入 | `-> "lib";` | 直接展开顶层声明 |

## 7. 零元运算符语句

| 语句 | 行为 |
|------|------|
| `break;` | 退出当前 `$$` 循环(仅在 `$$` 内生效) |
| `contiune;` | 结束当前 `$$` 循环迭代，重新求值条件(仅在 `$$` 内生效) |

- **零元运算符**：无操作数、独立成句、非一元非二元
- AST 分别为 `{"break":{"pos":[l,c]}}`、`{"contiune":{"pos":[l,c]}}`
- 标准库 `for`/`while`/`cycle` 基于 `$$` 实现，同样生效

## 8. 注解语句

> **签名**：`@ identifier # content #;`、`@ # content #;`
- 编译期收集进 `annotations`/`annotation`，**不进入 AST 语句列表**
- 详见 [词法：注解](lexical.md#注解)

## 9. 程序结构与编译产物

### 9.1 顶层结构

Tanex Script 程序 = **语句序列**(零或多条语句)，按顺序执行。无 `main` 函数入口概念，顶层语句即程序主体。

### 9.2 编译产物 JSON Schema

```json
{
  "Tanex Script": [
    // 语句1 AST 节点
    // 语句2 AST 节点
    // ...
  ],
  "annotations": {
    // 目标标识符: 注解内容字符串
  },
  "annotation": "文件级注解内容(可选，仅存在文件级注解时出现)"
}
```

- **`Tanex Script`**：数组，每个元素为一条语句的 AST 节点
- **`annotations`**：对象，键为注解目标标识符(含成员级 `Type.member`)，值为注解内容字符串
- **`annotation`**：字符串，仅当存在文件级注解时出现
- 所有 AST 节点均含 `pos: [line, column]` (1-based)
