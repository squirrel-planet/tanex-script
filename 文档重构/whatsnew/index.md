## 近期修订（2026-11）— 实现与文档对齐

> 以下为语法冻结后的实现修正与行为明确化，含一处运算符移除，请注意兼容性。

### 移除 `===` 网络运算符

- `===` 原为实验性 TCP 网关 JSON 收发运算符，已从词法、语法、运行时三处移除；对应核心文档《网络运算符 ===.md》已删除。
- **兼容性**：源码中使用 `===` 现在会在编译期报「意外的标记」；请改用标准库或 Python API 实现网络访问。
- 注意：`->` 才是展开运算符，与 `===` 无关。

### 标识符重声明规则

- 标识符一经 `*`/`**`/`***` 显式声明，不得换种类重新声明，必须先 `delete` 解绑再声明。
- `*a` 之后再次 `*a`（取地址）仍然合法，不会改变声明种类。

### 标准库行为明确化

| 函数/类型 | 变更 |
|-----------|------|
| `Number` 除法 | 截断到小数点后 3 位（不四舍五入），替换旧的 10 位实现；已重编译 `bootstrap.tscc` |
| `bit_not` | 明确为最小位宽补码；`n=0` 返回 `1` |
| `power_integer` | 改为 O(log exp) 二分快速幂，替换线性递归 |
| `ascii_encode` | 字符码超出 0-255 报错，不再产生非法字节 |
| `base_sixty_four_decode` | 遇非法 Base64 字符报错，不再静默跳过 |

> 修改 `standard_src/*.tsuc` 后须重新编译 `library/standard.tscl`；运行时只加载 `.tscc`/`.tscl`，不加载 `.tsuc`。

## Tanex Script 1.0.0 (2025-01-15) — 基线版本

> **语法冻结版本** — 此后不再变更语言语法，仅修复文档、补充示例、性能优化、标准库增量。

### 新增特性

#### 语言核心
- **语法统一化**：所有控制结构（`if`、`for`、`while`、`cycle`、错误处理）均为函数调用形式，无特殊关键字语法
- **代码块一等公民**：`{...}` 产生 `code` 类型值，可赋值、传参、存储、动态构造
- **运算符重载协议**：通过类型特殊成员（`addition`、`greater`、`string`、`index`、`include` 等 28 个槽位）自定义 30+ 运算符行为
- **显式地址与引用语义**：`/` 取地址、`*` 解地址、`**` 引用声明、`***` 常量声明、`&`/`&&`/`&&&` 连续声明
- **精确十进制数值**：`Number` 类型内部 `front/back` 表示，无浮点误差
- **注解系统**：`@ ident # content #;` 编译期收集、运行时 `??` 读取、库隔离空间
- **模块系统**：`import`/`->` 表达式符号，支持静态预编译与动态运行时加载双模式

#### 类型系统
- **三大类型分类**：原类型(`integer`)、基类型(`type_type`)、复合类型(7 种内置 + 用户自定义)
- **元类型机制**：`type_type` 自身继承自身，所有类型为其实例
- **继承与成员复制**：`inherit` 指向父类型，全量复制成员（跳过 `addable`/`external_read_only`/`inherit`）
- **真值判定协议**：`Integer` 非零为真、实例调用 `boolean` 特殊成员、其余默认真
- **比较兜底链**：直接特殊成员 → 组合兜底 → `compare` 三路比较 → 对象同一性兜底

#### 标准库（8 个模块）
| 模块 | 导出数量 | 核心功能 |
|------|----------|----------|
| `standard` | 20+ | 类型构造辅助、基础算术、字符串/列表操作、I/O封装、反射、控制流辅助、函数式工具 |
| `maths` | 25 | 数学函数(gcd/lcm/素数/阶乘/幂/平方根/斐波那契/组合数)、常量(π/e/√2) |
| `numeral_system` | 10 | 2/8/10/16 进制互转 |
| `encoding.ascii` | 14 | ASCII 编解码、字符分类、大小写转换 |
| `encoding.base_sixty_four` | 2 | Base64 编解码 (RFC 4648) |
| `json` | 2 | JSON 序列化/反序列化 (支持 Integer/Number/String/Boolean/None/List/Dictionary) |
| `random` | 7 | LCG 随机数生成器、种子设置、多种分布采样、洗牌 |
| `bit` | 8 | 位运算(AND/OR/XOR/NOT/左移/右移)、二进制↔十进制转换 |

#### 运行时与工具链
- **编译产物**：`.tscc` (JSON AST)、`.tscl` (二进制库打包)
- **引导库**：`bootstrap.tsuc` → `bootstrap.tscc`，启动时最先加载填充核心类型
- **Python API**：解释器嵌入、编译器调用、值模型操作、地址空间/作用域管理、模块加载器、注解系统、错误诊断
- **REPL**：交互模式、内置常量(`path`/`program_path`/`args`)、多行输入支持

## 版本号规则

遵循语义化版本 `MAJOR.MINOR.PATCH`：

- **MAJOR**：语法/核心语义破坏性变更（需迁移指南、语法解冻评审）
- **MINOR**：向后兼容新增功能（标准库模块、内置函数、性能优化）
- **PATCH**：仅修复 Bug、文档勘误、示例补充

> **维护承诺**：1.x 系列保证语法稳定、语义兼容。所有破坏性变更仅在 2.0.0+ 且经核心团队评审通过。
