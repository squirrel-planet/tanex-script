## 运算符与表达式

### Q: 为什么 `\` 是整除不是续行符？
**A**: 语言设计决定。**换行符只是空白，不终结语句**，语句仅由分号 `;` 终结。`\` 被设计为二元整除运算符 (`n \ m`)，行尾写 `\` 会被解析为整除，把下一行首个表达式作右操作数。

```tanexscript
# 正确：直接换行
a = `10
+ `20
+ `30;  # => `60

# 错误：行尾 \ 被解析为整除
# a = `10 \   # 整除左操作数
# `2;         # 右操作数，等价 a = `10 \ `2 结果 5
```

### Q: `&&` 一元和二元怎么区分？
**A**: 由**解析位置**决定：
- **一元位置**（语句首、另一元/二元运算符后、`(` 后）：连续引用声明 `&& N`
- **二元位置**：逻辑与 `a && b`

```tanexscript
&& 3;     # 一元：声明 3 个引用连续空间
a && b;   # 二元：逻辑与
```

### Q: `$` 一元和二元怎么区分？
**A**: 
- **一元 `$ expr`**：返回/提前结束代码块
- **二元 `n $ m`**：多层跳出，向上穿透 n 层返回 m

```tanexscript
$ `42;           # 一元：返回 42
2 $ "escaped";   # 二元：跳出 2 层返回 "escaped"
```

### Q: 为什么 `and`/`or`/`not`/`is` 是关键字别名？
**A**: 提供类英语可读性，**词法阶段自动替换**为运算符，**不增加语法复杂度**：

| 关键字 | 替换为 |
|--------|--------|
| `and` | `&&` |
| `or` | `||` |
| `not` | `!` |
| `is` | `==` |

解析器仅见运算符 Token，无别名语义差异。

### Q: 管道 `|>` 右侧必须是函数引用吗？
**A**: **是的**。`|>` 语义是首参注入：`a |> f` 等价 `f(a)`。右侧**必须**求值为函数值（标识符/成员访问/类型构造器），**不支持** `a |> f(b)` 形式。

```tanexscript
# 正确
`5` |> [*x] => { $ x * `2; }  # => `10
"hello" |> std.string.upper    # 成员访问

# 错误
# `5` |> add(`3)  # 右侧是调用表达式，不支持
```

## 控制流

### Q: 为什么 `if`/`for`/`while` 是函数不是关键字？
**A**: **语法统一化**设计：
- 消除特殊关键字语法，语法规则极简一致
- 代码块作为 `code` 类型值，可像普通数据一样传递、组合
- 支持自定义控制结构（如 `retry`、`until`、`times`）

```tanexscript
# 标准库实现示例
*** if = [*cond, *then, *else] => {
    cond ? { then(); } : { else(); };
};

*** for = [*var, *iter, *body] => {
    * i = `0;
    { i < iter.size } $$ {
        var = iter.index(i);
        body();
        i = i + `1;
    };
};
```

### Q: `break`/`contiune` 只在 `$$` 内生效？
**A**: **是的**。它们是**零元运算符**，仅在 `$$` 循环符内生效。标准库 `for`/`while`/`cycle` 基于 `$$` 实现，**间接生效**。

```tanexscript
# 直接用 $$
{ $ i < `5; } $$ { i = i + `1; break; }  # 直接生效

# 通过标准库函数（间接生效）
for(* i, [`1`..`5`], { i == `3 ? { break; } : {}; });  # 生效
```

### Q: `cycle` 和 `while` 有什么区别？
**A**: 
- `cycle(n, body)`：执行 body 恰好 n 次，无条件判断
- `while(cond_code, body)`：反复执行 cond_code，真则执行 body

```tanexscript
cycle(`3`, { println("hi"); });  # 固定 3 次

* c = `0;
while({ $ c < `3; }, { println(c); c = c + `1; });  # 条件循环
```

### Q: `$$` 循环符怎么用？
**A**: `条件 $$ 循环体` —— 收集 `$` 返回值形成列表：

```tanexscript
* i = `1;
{ $ i <= `5; } $$ { $ i; i = i + `1; };
# => [`1`, `2`, `3`, `4`, `5`]

# $ 语义变为收集，不结束循环
# break 退出，contiune 跳过本轮
```

## 类型系统

### Q: `integer` 和 `number` 有什么区别？
**A**: 

| 特性 | `integer` (原类型) | `number` (复合类型) |
|------|-------------------|---------------------|
| 字面量 | `` `42` `` | `'3.14'` |
| 内部表示 | 直接整数值 | `front` + `back` + `scale` |
| 精度 | 任意精度整数 | 精确十进制小数 |
| 运算 | 整数运算 | 对齐小数位、进位 |
| 除零 | `/`→`infinite` | `/`→`infinite` |

### Q: 为什么 `number` 除法精度有限？
**A**: 当前实现**截断到小数点后 3 位精度**（避免无限循环小数）。

```tanexscript
`1` / `3`;  # => '0.333' (非无限循环)
```

### Q: 如何判断值的真假？
**A**: 真值判定规则：

| 值类型 | 真值 |
|--------|------|
| `Integer` | 非零为真 |
| `Number` | 非零为真 |
| `String`/`List` | 非空为真 |
| `Boolean` | `true` 为真 |
| `None`/`NaN` | 恒假 |
| `Infinite` | 恒真 |
| 实例/类型/代码块/地址/库 | 默认真（除非类型定义 `boolean` 特殊成员） |

### Q: 什么是特殊成员？
**A**: 类型上具有**运行时语义**的成员，运行时识别并参与运算符重载、转换协议：

| 类别 | 特殊成员 | 触发场景 |
|------|----------|----------|
| 构造/转换 | `initialize`、`boolean`、`string`、`include`、`index` | 构造、真值、输出、in、下标 |
| 算术(7) | `addition`、`subtract`...`power` | `+` `-` `*` `/` `\` `%` `^` |
| 一元(2) | `positive`、`negative` | `+n` `-n` |
| 比较(6) | `greater`...`not_equal` | `>` `<` `>=` `<=` `==` `!=` |
| 三路比较 | `compare` | 最后兜底 |
| 行为控制 | `addable`、`external_read_only` | 新增成员、只读成员 |

## 作用域与闭包

### Q: 变量查找顺序是怎样的？
**A**: **词法作用域**，当前层 → 父层 → 祖先层 → 顶层。找到即返回。

```tanexscript
* x = `1;
{
    * x = `2;  # 遮蔽外层
    x;        # => `2
    ~x;       # => `1 (父作用域)
}
```

### Q: 闭包捕获的是值还是地址？
**A**: **地址**（存储单元）。外层变量修改对闭包可见，闭包内修改对外层可见。

```tanexscript
*** make_counter = [*init] => {
    * count = init;
    [*] => { count = count + `1; $ count; };
};

* c1 = make_counter(`0);
* c2 = make_counter(`100);
c1();  # => `1
c1();  # => `2
c2();  # => `101 (独立环境)
```

### Q: 上级访问 `~` 能穿透多少层？
**A**: 可连续：`~~x` 访问祖父层，`~~~x` 曾祖父层，直到顶层。无父作用域时报错。

## 模块系统

### Q: `import` 和 `->` 什么区别？
**A**: 

| 特性 | `import` | `->` |
|------|----------|------|
| 产生句柄 | ✅ `Library` 常量 | ❌ |
| 作用域污染 | 无 | 是(展开顶层声明) |
| 命名引入 | ✅ `import "lib" = *m` | ❌ |
| 注解隔离 | ✅ 独立空间 | ❌ 合并到全局 |

### Q: 动态 import 路径怎么写？
**A**: 操作数为任意表达式，**运行时求值**：

```tanexscript
import "lib_" + suffix + ".tsuc";
import get_plugin_path();  # 函数调用返回路径
```

### Q: 导入歧义怎么解决？
**A**: 同名多内容报错，建议加后缀：

```tanexscript
import "lib/";      # 文件夹加 /
import "lib.tsuc";  # 文件加后缀
import "lib.tscl";  # 编译库
import "/abs/path/lib";  # 绝对路径
```
