# 废弃项清单

> 对标 [Python Deprecations](https://docs.python.org/zh-cn/3.16/deprecations/)
>
> 记录已弃用、计划移除的语言特性与标准库接口，并给出迁移方案。

---

## 当前状态

Tanex Script 1.0.0 为**语法冻结基线版本**，目前**没有处于弃用流程中的语言特性或标准库接口**。

下列项目属于实验性功能的直接撤销，而非弃用流程，列此备查：

| 项目 | 状态 | 说明 |
|------|------|------|
| `===` 网络运算符 | 已移除 (2026-11) | 实验性 TCP 网关 JSON 收发运算符，已从词法、语法、运行时三处删除。源码中使用会在编译期报「意外的标记」；需要网络访问请改用标准库或 Python API。 |

> 注意：`->` 是展开运算符，与已移除的 `===` 无关。
