# 运算符

运算符是[表达式](表达式.md)组成的一部分，用于表达计算的方法

每个运算符在编译后都会生成对应的AST节点。

## 运算符类型

### 一元运算符

一元运算符作用于单个操作数。

| 运算符 | AST格式 | 说明 |
| -------- | --------- | ------ |
| `~n` | `{"unary":{"operator":"~","operand":n,"pos":[l,c]}}` | 上级访问 |
| `!n` | `{"unary":{"operator":"!","operand":n,"pos":[l,c]}}` | 逻辑非 |
| `+n` | `{"unary":{"operator":"+","operand":n,"pos":[l,c]}}` | 正号（用户类型可用 `positive` 特殊成员自定义） |
| `-n` | `{"unary":{"operator":"-","operand":n,"pos":[l,c]}}` | 负号（用户类型可用 `negative` 特殊成员自定义） |
| `*n` | `{"unary":{"operator":"*","operand":n,"pos":[l,c]}}` | 解地址 |
| `/n` | `{"unary":{"operator":"/","operand":n,"pos":[l,c]}}` | 取地址 |
| `** n` | `{"unary":{"operator":"**","operand":n,"pos":[l,c]}}` | 引用声明 |
| `*** n` | `{"unary":{"operator":"***","operand":n,"pos":[l,c]}}` | 常量声明 |
| `<- n` | `{"unary":{"operator":"<-","operand":n,"pos":[l,c]}}` | 报错 |
| `$ n` | `{"unary":{"operator":"$","operand":n,"pos":[l,c]}}` | 返回（一元）；另见二元 `n $ m` 多层跳出 |
| `return n` | `{"unary":{"operator":"return","operand":n,"pos":[l,c]}}` | 返回 |
| `?? n` | `{"unary":{"operator":"??","operand":n,"pos":[l,c]}}` | 注解读取（有作用域，支持 `?? 库.成员`；查不到报错） |
| `& n` | `{"unary":{"operator":"&","operand":n,"pos":[l,c]}}` | 连续声明：`& N` 声明 N 个普通连续空间 |
| `&& n` | `{"unary":{"operator":"&&","operand":n,"pos":[l,c]}}` | 连续声明：`&& N` 声明 N 个引用连续空间（一元位置；二元位置仍是 bool and） |
| `&&& n` | `{"unary":{"operator":"&&&","operand":n,"pos":[l,c]}}` | 连续声明：`&&& N` 声明 N 个常量连续空间 |
| `type_of n` | `{"unary":{"operator":"type_of","operand":n,"pos":[l,c]}}` | 获取值的类型 |

声明符 `*`、`**`、`***` 的操作数为 `integer`/`number` 字面量时为数量声明：连续声明 N 个空间并返回列表 `[start, end]`（首末地址；`*N` 普通、`**N` 引用、`***N` 常量）；数量须为正整数，非整数 `number` 报错（如 `** '3.14'` 报「'3.14' 不是整数」）。`&`/`&&`/`&&&` 是三个独立的一元运算符，操作数须为 `integer`/`number` 字面量，分别等价于 `*N`/`**N`/`***N` 的数量声明形式（如 `& 3` 等价 `* 3`）；`&&` 一元是连续引用声明，与二元 bool and 由解析位置区分。详见[声明](声明.md)。

### 二元运算符

二元运算符作用于两个操作数。

| 运算符 | AST格式 | 说明 |
| -------- | --------- | ------ |
| `n\|>m` | `{"binary":{"operator":"\|>","left":n,"right":m,"pos":[l,c]}}` | 管道：首参注入，`n |> f` 等价于 `f(n)`；右侧必须是函数引用（标识符/成员），不支持带参调用形式；链式左结合，支持跨库/成员调用 |
| `n+m` | `{"binary":{"operator":"+","left":n,"right":m,"pos":[l,c]}}` | 加法/拼接 |
| `n-m` | `{"binary":{"operator":"-","left":n,"right":m,"pos":[l,c]}}` | 减法 |
| `n*m` | `{"binary":{"operator":"*","left":n,"right":m,"pos":[l,c]}}` | 乘法/重复 |
| `n/m` | `{"binary":{"operator":"/","left":n,"right":m,"pos":[l,c]}}` | 除法 |
| `n\m` | `{"binary":{"operator":"\\","left":n,"right":m,"pos":[l,c]}}` | 整数除法 |
| `n%m` | `{"binary":{"operator":"%","left":n,"right":m,"pos":[l,c]}}` | 取余 |
| `n^m` | `{"binary":{"operator":"^","left":n,"right":m,"pos":[l,c]}}` | 幂运算 |
| `n<<m` | `{"binary":{"operator":"<<","left":n,"right":m,"pos":[l,c]}}` | 输出 |
| `n>>m` | `{"binary":{"operator":">>","left":n,"right":m,"pos":[l,c]}}` | 输入 |
| `n$$m` | `{"binary":{"operator":"$$","left":n,"right":m,"pos":[l,c]}}` | 循环符 |
| `n$m` | `{"binary":{"operator":"$","left":n,"right":m,"pos":[l,c]}}` | 二元跳出：`n` 必须为正整数，从当前层向上跳出 n 层返回目标并返回 `m`；`1 $ m` 等价 `return m`，层数不足时报错 |
| `n < m` | `{"binary":{"operator":"<","left":n,"right":m,"pos":[l,c]}}` | 小于 |
| `n<=m` | `{"binary":{"operator":"<=","left":n,"right":m,"pos":[l,c]}}` | 小于等于 |
| `n>m` | `{"binary":{"operator":">","left":n,"right":m,"pos":[l,c]}}` | 大于 |
| `n>=m` | `{"binary":{"operator":">=","left":n,"right":m,"pos":[l,c]}}` | 大于等于 |
| `n==m` | `{"binary":{"operator":"==","left":n,"right":m,"pos":[l,c]}}` | 等于 |
| `n!=m` | `{"binary":{"operator":"!=","left":n,"right":m,"pos":[l,c]}}` | 不等于 |
| `n&&m` | `{"binary":{"operator":"&&","left":n,"right":m,"pos":[l,c]}}` | 逻辑与 |
| `n\|\|m` | `{"binary":{"operator":"\|\|","left":n,"right":m,"pos":[l,c]}}` | 逻辑或 |
| `n in m` | `{"binary":{"operator":"in","left":n,"right":m,"pos":[l,c]}}` | 存在判断 |
| `n=m` | `{"assignment":{"operator":"=","left":n,"right":m,"pos":[l,c]}}` | 赋值 |
| `n+=m` | `{"assignment":{"operator":"+=","left":n,"right":m,"pos":[l,c]}}` | 加法赋值 |
| `n-=m` | `{"assignment":{"operator":"-=","left":n,"right":m,"pos":[l,c]}}` | 减法赋值 |
| `n*=m` | `{"assignment":{"operator":"*=","left":n,"right":m,"pos":[l,c]}}` | 乘法赋值 |
| `n/=m` | `{"assignment":{"operator":"/=","left":n,"right":m,"pos":[l,c]}}` | 除法赋值 |
| `n\=m` | `{"assignment":{"operator":"\\=","left":n,"right":m,"pos":[l,c]}}` | 整除赋值 |
| `n%=m` | `{"assignment":{"operator":"%=","left":n,"right":m,"pos":[l,c]}}` | 模赋值 |
| `n^=m` | `{"assignment":{"operator":"^=","left":n,"right":m,"pos":[l,c]}}` | 幂赋值 |
| `n&=m` | `{"assignment":{"operator":"&=","left":n,"right":m,"pos":[l,c]}}` | 与赋值 |
| `n\|=m` | `{"assignment":{"operator":"\|=","left":n,"right":m,"pos":[l,c]}}` | 或赋值 |
| `[a,b...]=>{...}` | `{"binary":{"operator":"=>","left":{"list":...},"right":{"code":...},"pos":[l,c]}}` | 匿名函数 |
| `n[m]` | `{"subscript":{"left":n,"right":m,"pos":[l,c]}}` | 下标访问 |
| `n{m1,m2...}` | `{"new":{"type":n,"include":[m1,m2...],"pos":[l,c]}}` | 创建实例 |
| `n.m` | `{"member":{"left":n,"right":{"name":{"value":m,"pos":[l,c]}},"pos":[l,c]}}` | 成员访问 |

### 三目运算符

| 运算符 | AST格式 | 说明 |
| -------- | --------- | ------ |
| `n ? a : b` | `{"ternary":{"operator":"?","condition":n,"true_branch":a,"false_branch":b,"pos":[l,c]}}` | 三目判断 |
| `left \| err : catch : else` | `{"try":{"left":left,"error_arg":err,"catch_block":catch,"else_block":else,"pos":[l,c]}}` | 尝试/错误处理 |

### in 运算符与 include 特殊成员

`n in m` 为存在判断。执行时**优先**查找右值 `m` 类型链上的 `include` 特殊成员：若存在，解释器调用 `include(m, n)`（receiver 为右值，参数为左值），返回值按真值转布尔作为 `in` 判定；若不存在 `include`，走原有兜底逻辑——要求右值类型注册 `index` 特殊成员，配合 `size` 从左到右遍历，左值等于任一元素则返回 `true`，否则 `false`。

### 零元运算符

零元运算符**没有操作数**，单独构成一条语句，非一元非二元。

| 运算符 | AST格式 | 说明 |
| -------- | --------- | ------ |
| `break;` | `{"break":{"pos":[l,c]}}` | 退出循环（零元运算符，无操作数，单独构成语句） |
| `contiune;` | `{"contiune":{"pos":[l,c]}}` | 立即结束当前循环迭代，进入下一轮条件判断（零元运算符，无操作数，单独构成语句） |

### 表达式符号（前缀运算符）

`import` 与 `->` 是**表达式符号**（Pratt 前缀运算符）：二者完全等价，操作数为任意表达式，运行时先对操作数求值得到字符串路径（单条）或路径列表（列表形式），再动态加载。不能作为中缀使用。

| 语法 | AST格式 | 说明 |
| -------- | --------- | ------ |
| `import <expr>;` / `-> <expr>;` | `{"import":{"path":<表达式AST节点>,"name":null,"pos":[l,c]}}` | 单条引入，运行时求值路径，默认以路径名为标识符 |
| `import <expr> = name;` / `-> <expr> = name;` | `{"import":{"path":<表达式AST节点>,"name":"name","pos":[l,c]}}` | 命名引入 |
| `import [expr1, expr2];` / `-> [expr1, expr2];` | `{"import":{"path":{"list":{"items":[...],"pos":...}},"name":null,"pos":[l,c]}}` | 列表批量引入，运行时逐个求值 |
| `import [expr1, expr2] = [n1, n2];` | `{"import":{"path":{"list":{"items":[...],"pos":...}},"name":["n1","n2"],"pos":[l,c]}}` | 列表批量引入并命名，名称数量须与路径数量一致 |

详见 [import 逻辑](import逻辑.md)。

### 关键字别名

以下关键字在词法分析时被自动替换为对应运算符：

| 关键字 | 替换为 |
| -------- | -------- |
| `and` | `&&` |
| `or` | `\|\|` |
| `not` | `!` |
| `is` | `==` |
