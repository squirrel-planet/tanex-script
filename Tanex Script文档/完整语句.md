# 完整语句

**语句**是 Tanex Script 程序中按顺序执行的代码片段。Tanex Script 中，每个语句都应该是完整的，即使是[注释](注释.md)或[注解](注解.md)。

每个语句都应该以结束符 `;` 结尾

## 语法

`...;`

## 语句的类型

### 普通语句

包括[注释](注释.md)、[注解](注解.md)、[break](break.md) 和 import 语句(`->`)。

import 语句用于引入其他 Tanex Script 文件或库，在预编译阶段解析、编译后成为 `import` 语句节点，运行时按命名空间加载：

```tanex script
-> "lib.tsuc";
-> "compiled.tscc";
-> "library_name";
```

引入后只会创建一个 `library` 类型的常量标识符，库内容通过该句柄访问，不会展开到全局作用域。

### 表达式语句

表达式语句是后跟分号的表达式。

Tanex Script 程序中的大多数语句都是表达式语句，例如赋值或函数调用。

### 空语句

表示一个只有结束符 `;` 而没有主要内容的语句，编译器会忽略它们。

## 编译后表示

整个程序文件编译后生成如下结构的 JSON：

```json
{
    "Tanex Script": [
        // 语句1的AST
        // 语句2的AST
        // ...
    ],
    "annotations": {
        // 目标标识符: 注解内容
    },
    "annotation": "文件级注解内容（存在文件级注解时才有）"
}
```

每条语句的AST节点即为该语句表达式的编译结果（如 `binary`、`unary`、`function` 等）。

`annotations` 字段记录了程序中的[注解](注解.md)：以目标标识符为键、注解内容为值。注解语句**不加入** `Tanex Script` 语句列表。

### 特殊语句 AST

| 语句 | AST 格式 | 说明 |
| ------ | --------- | ------ |
| `break;` | `{"break":{"pos":[l,c]}}` | 退出循环 |
| `@ 标识符 # 内容 #;` | 记录到 `annotations`，不在 AST 中；无标识符时记录到顶层 `annotation` | 注解语句 |
| `-> "path";` | 预编译阶段解析为 `import` 节点 | 导入语句，运行时加载为 `library` 常量 |
