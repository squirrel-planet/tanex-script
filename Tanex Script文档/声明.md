# 声明

**声明**是在 Tanex Script 程序中引入名称的方式。定义是足以使用名称所标识对象的声明。

## 简单声明

简单声明是引入、创建并可选的赋值一个标识符的表达式语句。

注：若在简单声明种为标识符赋值了，可以省略普通声明符 `*`。

### 简单声明语法

`* identifier;`
`* identifier = value;`
`identifier = value;`

### 数量声明

声明符的操作数为 `integer` 或 `number` 字面量时，声明连续 N 个空间，并返回列表 `[start, end]`（首末地址，`end` 与 `start` 相差 `N-1`）：

`* 3;` 声明 3 个连续空间
`** 3;` 声明 3 个连续引用空间
`*** 5;` 声明 5 个连续常量空间（首次绑定后不可修改）

数量必须是正整数：`integer` 字面量直接取数值；`number` 字面量须为整数值，否则报错，如 `** '3.14';` 报「'3.14' 不是整数」；数量小于 1 报「声明空间的数量必须 >= 1」。

### 一元连续声明运算符 & / && / &&&

`&`、`&&`、`&&&` 是三个独立的一元运算符，操作数为 `integer`/`number` 字面量，分别显式声明 N 个连续空间（对应 `*`/`**`/`***` 声明符的数量声明形式）：

`& 3;`   声明 3 个普通连续空间（等价于 `* 3`）
`&& 3;`  声明 3 个引用连续空间（等价于 `** 3`）
`&&& 3;` 声明 3 个常量连续空间（等价于 `*** 3`）

注意：
- `&&` 在**一元位置**是连续引用声明，在**二元位置**仍是 bool and（`and` 关键词等价），二者由解析位置区分，互不影响。
- `&` 的二元位与运算不受影响；`&&&` 只有一元形式。
- 操作数必须是 `integer`/`number` 字面量；操作数为标识符等非字面量时语法层报错（如 `& a` 报「连续声明操作数必须是整数」）。
- 常量连续空间（`&&& N`）不可再写入：通过地址解地址写入报「常量不可修改」。

## 引用声明

引用声明用于声明引用变量，使这个变量可以在该引用变量赋值的变量改变时同步变化。

注意：声明的引用变量只能赋值为一个标识符。

### 引用声明语法

`** identifier;`
`** identifier = value;`

## 常量声明/特殊标识符声明

该声明方式可以使声明后的标识符拥有不变的性质，若标识符内容特殊，可以作为特殊标识符声明

### 常量声明语法/特殊标识符声明语法

`*** identifier;`
`*** identifier = value;`

## 编译后表示

声明在编译后生成对应的 AST 节点：

| 声明类型 | 表达式 | AST格式 |
| -------- | ------ | --------- |
| 简单声明 | `* name` | `{"unary":{"operator":"*","operand":{"name":{...}},"pos":[l,c]}}` |
| 引用声明 | `** name` | `{"unary":{"operator":"**","operand":{"name":{...}},"pos":[l,c]}}` |
| 常量声明 | `*** name` | `{"unary":{"operator":"***","operand":{"name":{...}},"pos":[l,c]}}` |
| 数量声明 | `* N` / `** N` / `*** N` | `{"unary":{"operator":"*","operand":{"integer":{"value":"N","pos":[l,c]}},"pos":[l,c]}}` |
| 连续声明 | `& N` / `&& N` / `&&& N` | `{"unary":{"operator":"&","operand":{"integer":{"value":"N","pos":[l,c]}},"pos":[l,c]}}` |
| 赋值声明 | `name = value` | `{"assignment":{"operator":"=","left":{"name":{...}},"right":value,"pos":[l,c]}}` |
