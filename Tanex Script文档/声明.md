# 声明

**声明**是在 Tanex Script 程序中引入名称的方式。定义是足以使用名称所标识对象的声明。

## 简单声明

简单声明是引入、创建并可选的赋值一个标识符的表达式语句。

注：若在简单声明种为标识符赋值了，可以省略普通声明符 `*`。

### 简单声明语法

`* identifier;`
`* identifier = value;`
`identifier = value;`

## 引用声明

引用声明用于声明引用变量，使这个变量可以在该引用变量赋值的变量改变时同步变化。

注意：声明的引用变量只能赋值为一个标识符。

### 引用声明语法

`** identifier;`
`** identifier = value;`

## 常量声明/特殊标识符声明

该声明方式可以使声明后的标识符拥有不变的性质，若标识符内容特殊，可以作为特殊标识符声明

### 常量声明语法/特殊标识符声明语法

`*** identifier;`
`*** identifier = value;`

## 编译后表示

声明在编译后生成对应的 AST 节点：

| 声明类型 | 表达式 | AST格式 |
| -------- | ------ | --------- |
| 简单声明 | `* name` | `{"unary":{"operator":"*","operand":{"name":{...}},"pos":[l,c]}}` |
| 引用声明 | `** name` | `{"unary":{"operator":"**","operand":{"name":{...}},"pos":[l,c]}}` |
| 常量声明 | `*** name` | `{"unary":{"operator":"***","operand":{"name":{...}},"pos":[l,c]}}` |
| 赋值声明 | `name = value` | `{"assignment":{"operator":"=","left":{"name":{...}},"right":value,"pos":[l,c]}}` |
