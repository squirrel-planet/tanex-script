# 表达式

表达式是**运算符**及其**操作数**的序列，它指定了计算。

表达式求值可能会产生结果（例如，`'2' + '2'` 的求值产生结果 `'4'`）。

每个 Tanex Script 表达式都由两个独立的属性来表征：[值](值.md)和[运算符](运算符.md)。

## 编译后表示

每个表达式在编译后都会生成 AST 节点。基本节点类型包括：

| 节点类型 | 说明 |
| --------- | ------ |
| `unary` | 一元运算符表达式 |
| `binary` | 二元运算符表达式 |
| `ternary` | 三目运算符表达式 |
| `try` | 尝试/错误处理表达式 |
| `assignment` | 赋值表达式 |
| `subscript` | 下标访问表达式 |
| `member` | 成员访问表达式 |
| `function` | 函数调用表达式 |
| `new` | 创建类型实例表达式 |
| `break` | 零元运算符表达式（无操作数，单独构成语句，退出循环） |
| `contiune` | 零元运算符表达式（无操作数，单独构成语句，立即结束当前循环迭代） |
| `import` | 表达式符号（Pratt 前缀运算符），操作数为任意路径表达式，运行时求值后动态加载 |
| `code` | 代码块字面量 |
| `list` | 列表字面量 |

`import` 与 `->` 完全等价，AST 统一为 `{"import":{"path":<表达式AST节点>,"name":<标识符或null或标识符列表>,"pos":[l,c]}}`。支持单条（`import <expr>;`）、命名（`import <expr> = name;`）、列表（`import [expr1, expr2];`、`import [expr1, expr2] = [n1, n2];`）三种形式，路径可为任意表达式，详见 [import 逻辑](import逻辑.md)。

## 字面量表达式

字面量直接在 AST 中表示为对应类型的节点：

| 字面量 | AST节点类型 |
| -------- | ------------ |
| `123` | `integer` |
| `'3.14'` | `number` |
| `"hello"` | `string` |
| `true`/`false` | `boolean` |
| `none` | `none_type` |
| `nan` | `nan_type` |
| `infinite` | `infinite_type` |

所有 AST 节点均包含 `pos:[l,c]` 字段记录源码位置。

## 特殊规则

### 函数调用参数

函数调用的 `arg` 始终为列表：
- 无参 `f()` → `"arg": []`
- 单参 `f(a)` → `"arg": [a]`
- 多参 `f(a, b)` → `"arg": [a, b]`

### 列表尾部逗号

列表或参数列表中的尾部逗号会自动填充 `none`：
- `[a,]` → `"items": [a, {"none_type": {"value": "none", ...}}]`
- `(a,,b)` → 中间空位也填充 `none`
