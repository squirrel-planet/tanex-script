# 网络运算符 `===`

`===` 是 Tanex Script 的中缀网络运算符，用于通过 TCP 连接网关，发送 JSON 请求并接收 JSON 响应。它是语言与外部程序（Python、Node 等）之间进行数据交换的桥梁。

## 语法

```Tanex Script
"host:port" === 可序列化值
```

- **左侧**：必须是字符串，格式为 `host:port`。省略 host 时默认 `127.0.0.1`（如 `"12345" === request` 等价于 `"127.0.0.1:12345" === request`）。
- **右侧**：任意可 JSON 序列化的值。
- **求值结果**：网关返回的 JSON 反序列化值（dictionary / list / integer / string / boolean / number / none）。

## 语义

1. 将右侧值序列化为 JSON 文本，末尾附加换行符 `\n`，通过 TCP 发送给左侧地址。
2. 阻塞读取响应，直到收到首个 `\n`，将该行按 JSON 反序列化。
3. 连接与读取各超时 10 秒；连接失败、无响应或 JSON 解析失败时抛出 `runtime_error`。
4. 通信协议为「一请求一响应、换行分隔」：请求以 `\n` 结尾，响应同样以 `\n` 结尾。

## 可序列化值

`===` 右侧支持以下 Tanex Script 值，序列化规则：

| Tanex Script 值 | JSON 类型 |
| --- | --- |
| integer | 数字 |
| string | 字符串 |
| boolean | true / false |
| number | 数字（浮点） |
| none | null |
| list | 数组 |
| dictionary | 对象 |

不支持的值（如 function、type 等）会抛出 `=== 右侧包含无法序列化为 JSON 的值`。

## 响应反序列化规则

JSON 响应反序列化为对应的 TSuc 值：

| JSON 类型 | TSuc 值 |
| ----------- | --------- |
| 对象 | dictionary（可通过 `.index("键")` 取值） |
| 数组 | list |
| 字符串 | string |
| 数字 | integer 或 number |
| true / false | boolean（可用 `==` 与 `true` / `false` 比较） |
| null | none |

## 完整示例

### 1. 网关服务端（Python）

`examples/gateway/gateway_server.py`：监听 `127.0.0.1:12345`，收到一行 JSON 请求后调用外部程序（如 `file_reader.py`），将结果作为一行 JSON 响应回传。

### 2. TSuc 客户端

`examples/gateway/test_gateway.tsuc`：

```Tanex Script
# 构造请求：请求网关调用外部程序读取指定文件 #;
* request = dictionary{[
    ["program", "file_reader.py"],
    ["path", "E:/代码/项目/Tanex Script/examples/gateway/data.txt"]
]};

# 发送请求并接收响应（=== 的求值结果就是网关返回的 JSON 反序列化值） #;
* response = "127.0.0.1:12345" === request;

# 检查响应字段并输出 #;
* ok = response.index("ok");
ok == true ? { standard.output("请求成功"); } : { standard.output("请求失败"); };
standard.output("\n");

* content = response.index("content");
standard.output("文件内容:");
standard.output("\n");
standard.output(content);
standard.output("\n");

* lines = response.index("lines");
standard.output("行数:");
standard.output(lines, false);
standard.output("\n");
```

运行输出：

```Tanex Script
请求成功
文件内容:
Hello, Tanex Script!
This is a gateway demo.
The === operator works.

行数:3
```

## 注意事项

- 网关地址必须是 `host:port` 形式，端口部分必须为纯数字，否则抛出 `无效的网关地址`。
- 响应必须为单行 JSON（以 `\n` 结尾），多行 JSON 或非 JSON 文本会导致解析失败。
- 网关未启动或地址不可达时抛出 `无法连接网关`，请先启动网关服务端再运行客户端。
- `===` 求值结果为 dictionary 时，取字段用 `response.index("键")`；boolean 字段与 `true` / `false` 比较请使用 `==`（`boolean.equal` / `boolean.not_equal` 已内置）。
- 数字字段（如 `lines`）直接输出时会被当作 Unicode 码点，需用 `standard.output(值, false)` 输出十进制数字文本。
