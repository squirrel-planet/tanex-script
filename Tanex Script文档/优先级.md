# 优先级

以下为 Tanex Script 运算符**优先级**（从高到低）

| 优先级 | 内容 | AST格式 | 说明 |
| -------- | ------ | --------- | ------ |
| 1 | 单值 | `{"integer"/"number"/"string"/"boolean"/...}` | 字面量 |
| 2 | `()` | 直接返回内部表达式AST | 括号 |
| 3 | `$` | `{"unary":{"operator":"$","operand":n,"pos":[l,c]}}` | 返回 |
| 4 | `*[]` | `{"subscript":{"left":n,"right":m,"pos":[l,c]}}` | 下标 |
| 4 | `* (单值...)` | `{"function":{"name":f_ast,"arg":single_or_list,"pos":[l,c]}}` | 函数调用 |
| 5 | `*.*` | `{"member":{"left":n,"right":{"name":...},"pos":[l,c]}}` | 成员访问 |
| 6 | `!` `~` `*` `/` `**` `***` `<-` `return` `??` | `{"unary":{"operator":"...","operand":n,"pos":[l,c]}}` | 一元运算符 |
| 7 | `+` `-` (一元) | `{"unary":{"operator":"+/-","operand":n,"pos":[l,c]}}` | 正负 |
| 8 | `*n` `/n` | `{"unary":{"operator":"*/","operand":n,"pos":[l,c]}}` | 地址运算 |
| 9 | `*` `/` `\` `%` `^` `<<` `>>` `$$` | `{"binary":{"operator":"...","left":n,"right":m,"pos":[l,c]}}` | 乘除/输出/输入/循环 |
| 10 | `+` `-` | `{"binary":{"operator":"+/-","left":n,"right":m,"pos":[l,c]}}` | 加减 |
| 11 | `<` `<=` `>` `>=` `in` | `{"binary":{"operator":"...","left":n,"right":m,"pos":[l,c]}}` | 比较/存在 |
| 12 | `==` `!=` `?` `\|` | `{"binary"/"ternary"/"try":{...}}` | 等于/三目/尝试 |
| 13 | `&&` | `{"binary":{"operator":"&&","left":n,"right":m,"pos":[l,c]}}` | 与 |
| 14 | `\|\|` | `{"binary":{"operator":"\|\|","left":n,"right":m,"pos":[l,c]}}` | 或 |
| 15 | `=>` | `{"binary":{"operator":"=>","left":{"list":...},"right":{"code":...},"pos":[l,c]}}` | 匿名函数 |
| 16 | `=` | `{"assignment":{"operator":"=","left":n,"right":m,"pos":[l,c]}}` | 赋值 |
| 17 | `+=` `-=` `*=` `/=` `%=` `^=` `&=` `\|=` `\=` | `{"assignment":{"operator":"...","left":n,"right":m,"pos":[l,c]}}` | 复式赋值 |

更多AST格式详见 [Tanex Script 语法](Tanex%20Script%20语法.md#ast-抽象语法树-格式)
