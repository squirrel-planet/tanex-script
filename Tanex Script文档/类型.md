# 类型

所有的值都具有一个称为**类型**的属性，该属性既限制了这些值允许的操作，又为原本通用的位序列提供了语义含义。

## 类型分类

Tanex Script 类型只有三种：[原类型](原类型.md)、[基类型](基类型.md)和[复合类型](复合类型.md)。

## AST 中的类型表示

在编译后的AST中，不同类型的值使用不同的节点类型：

| AST节点类型 | 对应类型 | 示例值 |
| ------------ | -------- | ------ |
| `integer` | 原类型 | `{"value":"123"}` |
| `number` | 复合类型 | `{"value":"'3.14'"}` |
| `string` | 复合类型 | `{"value":"\"hello\""}` |
| `boolean` | 复合类型 | `{"value":"true"}` |
| `none_type` | 复合类型 | `{"value":"none"}` |
| `nan_type` | 复合类型 | `{"value":"nan"}` |
| `infinite_type` | 复合类型 | `{"value":"infinite"}` |
| `name` | 标识符引用 | `{"value":"variable"}` |
| `list` | 复合类型 | `{"items":[...]}` |
| `code` | 复合类型 | `{"statements":[...]}` |

所有类型节点均包含 `pos:[l,c]` 字段。
