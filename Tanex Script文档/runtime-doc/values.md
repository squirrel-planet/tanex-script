# values — 运行时值类型

定义 Tanex Script 语言在运行时使用的各种值形式。这里的每一类都对应语言文档中已经定义的概念，不涉及具体实现语言的内部结构。

---

## 存储单元

运行时把每个值装进独立的存储单元，再放进地址空间，通过地址存取。每个存储单元有两个属性：

- **存放的值**：初始为全局唯一的空值 `none`，之后可反复放入不同值。
- **常量标记**：一旦被标记为"常量"，后续任何写入都被拒绝。这是语言中 `***` 只读声明在运行时的保证。

**机制**：读写都经过存储单元这层中转，因此"常量不可变"只需在唯一入口拦截，不需要每个调用点各自检查。

---

## 基类型 type_type

基类型是所有类型的基本，由解释器内部提供，用于定义复合类型。它继承于 `type_type` 自身，拥有 `type_type` 类型的成员 `inherit`（继承目标）。

一个类型对象记录：

- **构造器 init**：创建该类型实例时调用的函数。如果不存在，则该类型不能通过 `类型名{...}` 语法构造。
- **继承目标 inherit**：指向另一个类型对象。当在当前类型上找不到某个成员时，会沿着继承链向上查找。
- **特殊成员**：`boolean`、`string`、`index`、七个算术成员（`addition`、`subtract`、`multiply`、`divide`、`exactly_divisible`、`modulo`、`power`）、一元正负成员（`positive`、`negative`）、六个比较成员（`greater`、`less`、`greater_equal`、`less_equal`、`equal`、`not_equal`）与三路比较成员 `compare`，分别支撑真值判断、`<<` 输出、`a[b]` 下标、七个算术运算符、`+n`/`-n` 一元正负号、六个比较运算符及其最后兜底。
- **成员字典**：类型上定义的所有成员名，每个名字映射到地址空间中的一个地址。

**机制**：这些特殊成员是"运算符重载"的实现基础。解释器遇到算术运算符、比较运算符、`<<`、`a[b]`、条件判断时，先看对应对象的类型有没有注册特殊成员，有就调用——例如 `<<` 查的是右操作数类型的 `string` 特殊成员，`a[b]` 查的是左操作数类型的 `index` 特殊成员。语言中的 `*** 类型.xxx = 函数` 就是注册它们的方式。

---

## 实例

复合类型的值称为实例。一个实例包含：

- **类型**：指向创建它的类型对象，通过它可以找到类型上定义的方法与特殊成员。
- **成员**：实例自身的成员名到地址的映射。

**机制**：成员查找遵循"实例成员 → 类型成员 → 继承链"的顺序。实例成员优先于类型成员，因此实例可以覆盖类型上定义的默认成员。

（原类型 `integer` 不产生实例，见下文。）

---

## 原类型 integer

原类型 `integer` 是无包裹、无成员、无需导入的类型，表示一个无符号整数。运行时不把它包装成实例，值直接以整数形式参与运算。

---

## 地址值 address

`/变量` 取址得到的就是 `address` 类型的值。它内部保存该变量在地址空间中的地址。解引用 `*地址值` 通过这个地址取回实际的值。

**机制**：`**` 引用声明本质上是把"地址的地址"存入新的存储单元，再用该名字声明指向它——于是两个名字指向同一处存储，任一变、另一个同步变。

---

## 代码块 code

代码块是"尚未执行的语句集合"，用 `{}` 包裹。它保存：

- **语句列表**：待执行的语句。
- **定义时所在的作用域**：被调用时基于它建立子作用域。
- **参数信息**：作为函数被调用时的参数名与默认值（仅 `=>` 匿名函数带参数信息）。

**机制**：代码块被调用时依次执行每条语句，结果作为返回值；遇到 `$` 提前返回。`{}` 与 `=>` 都会产生代码块值，区别是 `=>` 额外携带参数信息，因此可以像函数一样被调用。`if`、`for` 等控制函数接收的参数正是代码块值。

---

## 空值 none

`none` 是 `none_type` 的唯一值，全程序只有一个。`none` 字面量、未赋值变量的初值、构造时的缺省值都指向它。

**机制**：正因为全局只有一份，`none == none` 恒成立。且 `none_type` 注册的 `boolean` 特殊成员恒返回假，所以 `none` 在一切条件判断中恒为假。
