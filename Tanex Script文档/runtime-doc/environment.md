# environment — 地址空间与作用域

定义值如何存储（地址空间）和名字如何查找（作用域）。这是运行时两大基础结构：地址空间管"值放在哪里"，作用域管"名字指向哪个地址"。

---

## 地址空间

地址空间是整个运行时的大仓库，所有值都按地址存放在里面。地址是一串唯一的字符，变量通过地址指向自己的值。

### 地址生成

- 地址从单个字符 `A` 开始，每分配一次就自增到下一位。
- 字符集共 63 个字符：大写字母、小写字母、数字、下划线（`A-Z a-z 0-9 _`）。
- 自增规则：从地址的最左边字符开始处理。如果当前字符不是字符集的最后一个，就换成下一个字符；如果是最后一个，就重置为 `A` 并进位到下一位。如果所有位都进位了，就在最左边补一个 `A`，长度增加一位。
- 例如：`A` → `B` → ... → `Z` → `a` → ... → `_` → `AA` → `AB` → ...

**机制**：这套自增规则等价于 63 进制计数——从最左边处理相当于从高位向低位进位，满 63 进一、位数不够时在前面补一位。地址因此永不重复、长度增长缓慢，既适合做唯一标识，又能从地址上直观看出分配的先后顺序。

### 分配

每次分配生成一个新地址，在该地址下建一个初始值为 `none` 的存储单元，并返回这个地址。

### 存取

- **读取**：给定地址，返回该地址存储单元中存放的值。
- **写入**：给定地址和一个值，把值放入该地址的存储单元。但如果该单元已被标记为常量，则拒绝写入并报错。

### 常量标记

把某个地址的存储单元标记为"只读"。之后任何尝试写入这个单元的操作都会失败。

**机制**：写入前检查常量标记，是语言 `***` 常量声明在底层的落点。`*** a = '100'` 会把 `a` 的存储单元标记为常量，之后任何 `a = ...` 都会被拦截并报错，从而保证"常量不可变"在语言层和存储层都是一致的。

### 存在检查

判断某个地址是否已被分配过。

---

## 作用域

作用域是变量名到地址的映射表，支持嵌套。每个变量名都对应一个地址，名字本身不存值，值在地址空间里。

### 结构

每个作用域有一个可选的父作用域。当前作用域查不到名字时，会自动向父作用域查找，一直追溯到最顶层。如果顶层也查不到，就报错。

### 声明变量

在**当前**作用域中注册一个名字，并关联到某个地址。只影响当前层，不影响父层。

**机制**：声明不做重名检查，直接覆盖当前层的映射。因此语言允许"遮蔽"——内层作用域可以定义与外层同名的变量，查找时内层优先；改名只影响内层，不影响外层。

### 查找地址

给定一个名字，先在当前层查，找到就返回对应的地址。当前层没有就去父层找。如果父层也没有，返回空（调用者自己决定是否报错）。

### 解析名字（查找 + 报错）

和查找地址一样，但如果最终没找到，直接报"变量未定义"错误，不再返回空。这是普通读取变量时使用的入口。

### 检查本地变量

只查当前作用域，不往父层找。用于判断一个名字是否在当前层声明过，解释器用它在 `*name` 声明时判断"该新建还是该复用"。

### 父作用域访问

向外暴露父作用域的引用，供解释器在需要时访问外层。

**机制**：语言中的 `~`（上级访问）运算符依赖它实现——`~expr` 求值时会把作用域临时换成当前作用域的父层，从而实现在"上一级"作用域里查名字的效果。
